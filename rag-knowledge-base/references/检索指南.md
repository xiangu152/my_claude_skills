# RAG 知识库检索指南

## 调用方式

当需要回答用户关于某个知识库的问题时：

```bash
python3 /Users/xiangu/Codes/agent/my_claude_skills/rag-knowledge-base/scripts/query_kb.py \
  --kb-name <知识库名> \
  --query "<用户问题>" \
  --top-k 5
```

## 检索参数

- `--top-k N`：返回 N 条最相关片段（默认 5，建议 3~8）
- `--json`：输出 JSON 格式（程序处理用）
- `--show-source`：显示来源文件路径

## 相似度距离

| 距离范围 | 含义 | 建议 |
|---------|------|------|
| < 0.5 | 非常相关 | 直接采用 |
| 0.5 ~ 0.7 | 相关 | 可以采用 |
| 0.7 ~ 0.8 | 一般 | 参考使用 |
| > 0.8 | 弱相关 | 多查几条或换查询词 |

## 优化检索的技巧

### 1. 调整查询词
- 用中文查询中文知识库效果更好
- 法术/怪物名称：中英混合（如 "火球术 fireball"）
- 专业术语：用知识库中实际使用的词汇

### 2. 调整 top-k
- 简单事实查询：top-k=3
- 需要综合多来源：top-k=5~8
- 非常具体的问题：top-k=2~3

### 3. 多次查询
- 如果首次检索弱相关，换一个角度重新查
- 不同查询词可能召回不同的片段
