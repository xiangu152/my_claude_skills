# 专利撰写 — Claude Code Skill

基于代码仓分析撰写中国专利申请书。逐节撰写、逐节审阅、每段论证都有来源。

## 解决的问题

| 问题 | 此 skill 的约束 |
|------|----------------|
| 从记忆/幻觉生成技术内容 | ⛔ 所有技术论断必须来自代码分析或网络检索 |
| 编造参考文献 | ⛔ 每个引用必须有可验证的 URL |
| 一口气写完整份专利 | ⛔ 逐节写，每节用户确认后才继续 |
| 闭门造车 | ⛔ 每节写之前必须搜索现有专利和技术文章 |
| 不理解代码就写 | ⛔ 必须先扫描代码仓、用户确认理解后才动笔 |

## 前置条件

- 已安装 Claude Code
- 已安装 `tavily-search`、`word-docx` skill
- 用户提供 DOCX 模板文件
- 目标代码仓

## 安装到 Claude Code

```bash
cp -r patent-writer ~/.claude/skills/
```

## 使用方式

### 触发方式

- "帮我写个专利"
- "基于这个代码仓撰写专利申请"
- "patent"

### 流程

```
Phase 1: 代码仓分析
  ├── 扫描目录结构、核心文件
  ├── 提取技术方案和创新点
  └── 用户确认 ← ⛔ 不能跳过

Phase 2: 创新点讨论
  ├── 逐个深入讨论技术细节
  ├── 确认权利要求结构
  └── 用户确认

Phase 3: 写前研究（每节都要做）
  ├── 搜索相关专利
  ├── 搜索技术文章
  ├── 找真实专利案例参考
  └── 整理参考资料（必须有 URL）

Phase 4: 逐节撰写
  ├── 技术领域 → 背景技术 → 发明内容 → 附图说明 → 具体实施 → 权利要求 → 摘要
  ├── 每节：研究 → 构思 → 撰写 → 验证 → 呈现 → 用户确认
  └── ⛔ 用户不确认就不能写下一节

Phase 5: DOCX 输出
  ├── 读取用户提供的模板
  ├── 按模板格式写入
  ├── 需要图的地方写结构化占位符
  └── 验证输出
```

### 附图处理

Claude Code 不能画图。需要图的地方用结构化占位符：

```
[附图 N]
图名：XXX系统架构图
类型：系统架构图
内容描述：
- 模块A：负责...
- 模块B：负责...
- 连接关系：A → B → C
用户需根据以上描述绘制图形。
```

### 依赖的其他 skill

| Skill | 用途 |
|-------|------|
| tavily-search | 搜索现有专利和技术文章 |
| word-docx | 读取模板、写入 DOCX |
| agent-browser | 浏览 Google Patents 等网站 |
